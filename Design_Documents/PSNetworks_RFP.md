# Packet Slinger Networks RFP

## Company Overview
Packet Slinger Networks is a fictitious Network Consultancy Services Provider that specializes in designing, auditing, and implementing network solutions for its SMB and residential customers. PSN is your friendly-neihgborhood network specialist - handling anything from Wi-Fi coverage assessments to office network builds.

## Project Overview
The objective of this Request for Proposal (RFP) is obtain proposals for the design and implementation of an adaptible and robust network infrastructure for Packet Slinger Networks' HQ office, 10 Regional Offices, and a total of 50 Branch offices. The network should implement industry-standard best practices and have room for potential growth. 

## Project Goals
1. Design an adaptable in robust network that can support the needs of Packet Slinger Networks:
    - Headquarters Office (Staff size: ~200)
    - Regional Offices (Staff size: ~50)
    - Remote Branch Office (Staff size: ~10)

2. Provide all necessary documentation for the project, including network infrastructure diagrams, Network Device Inventory/IP documentation.

3. Establish fault-tolerant connectivity between central HQ, regional offices, and remote branch offices.

4. Each branch office should support core employee traffice (data & voice) and provide proper segmentation for security cameras.

5. Implement proper newtork security measures to protect against both physical and technical threats.
    - Each Branch Office should have distinct network segments for employee traffic, VOIP communications, and camera feed
    - Each Regional Office should have the same network segments as the Branch Office, with the addition of a Guest network for visiting customers
    - The Headquarters Office should have the same network segments as a Regional Office, with the addition of a Servers network designed to house the PSN core services infrastructure.

6. Implement network loop prevention while optimizing network performance so that PSN customers receive the fastest and most reliable service.

## Project Scope of Work
The project requires the following tasks be completed:
1. Design of a new and improved network infrastructure (includes switches, routers, firewalls, and wireless access points)
2. Implementation and configuration of an IPv4 addressing scheme, routing protocols, segmented networks.
3. Installation and configuration of wireless connectivity.
4. Implementation of applicable network security measures and best practice.
5. Utilizing network automation to streamline network deployments for customers.
